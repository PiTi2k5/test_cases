Start oscillator(s) with fade in

This should start a number of oscillators (depending on which button you press).

Each oscillator is connected to its individual gain node, whose gain property is set to fade in from 0.0 to 1.0 and so that way we should avoid clippity clip sounds when the oscillator is started.

Results as of today 29 October 2024 (using macOS 13.7):

  • Firefox 133: it does NOT apply the ramp on the gain for some odd reason, the output starts noticeably saturated when playing 9+ voices
  • Chrome 130: applies the ramp, saturated with 2+ voices
  • Safari 18.0.1/605.1.15: seems to apply the ramp, but there is clipping. The recorded file is saturated with 2+ voices
